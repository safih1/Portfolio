Facebook Lead Ads

Pull leads from a lead form you own. Official Graph API only.

{{ 'Ready' if facebook_ready else 'Needs token' }}
How to get the token and form ID
  1. Create an app at developers.facebook.com.
  2. Add your Page and request leads_retrieval and pages_read_engagement.
  3. Generate a Page access token and save it as FACEBOOK_PAGE_ACCESS_TOKEN in .env.
  4. Set FACEBOOK_PAGE_ID. Open your lead forms in Meta Ads Manager to copy the form ID.
  5. Optional real-time: set the webhook callback to {{ url_for('facebook_webhook', _external=True) }}, use FACEBOOK_VERIFY_TOKEN, and subscribe to the Page's leadgen field.

This tool does not scrape Facebook or send automated DMs. Import an export you are allowed to use, or pull leads from forms you own.

Import a CSV

Facebook exports, LinkedIn exports, Apollo, spreadsheets — any file with headers.

Supported CSV headers

  • Namename, full_name, contact_name
  • Companycompany, business_name, organization
  • Emailemail, email_address, work_email
  • Phonephone, mobile, telephone, whatsapp
  • Websitewebsite, domain, url
  • Locationlocation, city, address, country
  • Notesnotes, description, comments

Headers are matched case-insensitively. Extra columns are ignored.
